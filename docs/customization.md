# Sauna customisation: customers and resellers

**Today.** Each of the six seeded models exposes option groups (wood, heater, control, door, bench layout/wood/front/end/edge, backrest, exterior, lighting, extras) through `sauna_model_option_groups` / `sauna_model_options`, priced per currency in `sauna_model_option_prices`, with `option_requires` / `option_excludes` rules. Resellers could already show/hide and order saunas (`reseller_saunas`), set PERCENT/FIXED discounts per sauna or as default (capped by the manufacturer, 0004/0007), and choose branding and storefront layout (0014). The manufacturer admin sets list and option prices. Prices are integer minor units; discounts are basis points or minor units, floored with BigInt (`@saunaklar/pricing`). The server is the source of truth: `loadModel` builds rules and prices, `@saunaklar/rules` validates selections on every save, and locking writes a price snapshot that `assert_configuration_lockable` re-checks in the database.

**Gap.** Customers choose from the manufacturer's full option list at manufacturer prices. A reseller cannot shape that list.

**Model (migration 0015).** One table, `reseller_sauna_options (reseller_id, sauna_model_id, option_id)`, stores only deviations: `is_enabled`, `price_override_minor` (reseller currency, replaces the manufacturer's option price, no markup arithmetic) and `description_override` (one text for every locale). No row means the manufacturer's values. Composite FKs to `reseller_saunas` and `sauna_model_options` (as `reseller_sauna_discounts` does) keep rows inside offered saunas and their options, cascading on unassignment. Tenant RLS gives own rows only; the manufacturer can read them. Statement triggers bump `catalog_version` (rule 9). The audit trail records availability and price, never the free text (rule 11).

**Rules.** A row trigger refuses to disable every option of a required group, or to disable an option that an enabled option requires (`OPTION_RULES_VIOLATED`). The API checks the same thing first so it can return field errors. `loadModel` drops disabled options from groups and rules, so a disabled option counts as an unknown option on create, save and send. The effective price feeds `livePrice`, the "from" price and the snapshot. The lock trigger compares snapshot lines with `coalesce(override, manufacturer price)` and rejects disabled options (`OPTION_DISABLED`).

**Surfaces.** `GET/PUT /api/admin/saunas/:id/options` (reseller admin, "Options and prices" per sauna). The public sauna detail lists only enabled options, with effective price and localised description (English fallback; groups now have descriptions too). The configurator prices from those values.
